Title: Month navigation — prev/next arrows
Status: done

## What to build

Add previous/next arrow buttons above the calendar grid to navigate between months. Past months show the historical mock session data (completed/skipped). Future months show planned sessions, becoming progressively sparser further from the current month. The current month label (e.g. "June 2026") updates as the athlete navigates.

## Acceptance criteria

- [ ] Prev/next arrow buttons navigate one month at a time
- [ ] Current month name and year are displayed above the grid
- [ ] Past months render historical sessions (solid/muted dots)
- [ ] Future months render planned sessions (outline dots), sparser 2+ months out
- [ ] Navigating back to current month works correctly
- [ ] Day highlighting (today) only appears on the current month
