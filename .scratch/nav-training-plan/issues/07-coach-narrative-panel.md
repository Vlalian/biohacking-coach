Title: Coach narrative panel
Status: done

## What to build

Add a Coach narrative section to the Training Plan view, positioned above or alongside the calendar. The narrative is a short paragraph (2–3 sentences) contextualising the current Training Phase: where the athlete is in their build, what this week is developing, and why. Content is hardcoded per Training Phase, written in the Coach's Peer Authority voice. Updates automatically when the Training Phase changes in the check-in.

## Acceptance criteria

- [ ] Coach narrative renders above the calendar grid
- [ ] Each Training Phase has distinct narrative text in Peer Authority voice
- [ ] Narrative updates when Training Phase is changed in the check-in
- [ ] Styled consistently with the existing Coach bubble / dark theme
- [ ] No markdown rendering — plain text only
