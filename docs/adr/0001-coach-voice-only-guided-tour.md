# Coach voice only for the guided tour

Status: accepted (2026-07-08)

New athletes learn the product entirely through the Coach's voice at contextually appropriate moments — no UI overlays, tooltips, or arrow-based walkthroughs. The First Weekly Session Closing is the primary delivery mechanism. This was chosen because a tooltip tour signals "app"; a Coach-delivered orientation signals "coaching relationship" — consistent with Peer Authority and the product's core value proposition. The trade-off: the tour is harder to control and cannot be replayed on demand, but this is acceptable because re-explaining features on request is a natural Coach Chat use case.
